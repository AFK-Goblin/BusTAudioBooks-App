# BusTAudioBooks 3.3.2

Android home-screen widgets now come in five sizes: 1×4 column, 4×1 player bar, 2×2 compact, 2×3 cover and 4×2 wide. Widgets adapt as you resize them and share the app's playback controls and listening progress.

Also included since the previous GitHub release:

- Private personal libraries with phone and Windows progress sync.
- Fixes for missing synced books and listening progress disappearing from Continue listening.
- Scrolling long chapter titles and a setting to show chapters below the player or in a separate menu.
- Playback, download and navigation improvements.

Install the attached Android APK over your existing app. Do not uninstall first. Widgets include native Android components, so installing this APK is required even if you already receive in-app updates. After installation, open BusTAudioBooks once, then use your launcher's widget picker to add a widget. Available cell dimensions depend on your launcher.

This release contains the Android installer. Windows source improvements are included in the repository; Windows installers and their automatic-update feed use separate desktop releases.
