BusTAudio for Windows 1.1.0 brings the phone's dark plum theme and accent colours to the desktop, a cleaner library and player, and automatic updates for installed copies.

Close the old portable app, then run BusTAudio-Setup-1.1.0-x64.exe once. Your existing app data is retained under the same Windows account. Use the installed Start menu shortcut from now on. Future published updates download in the background; choose Restart to update when convenient. Progress is saved first and unresolved library changes prevent an update restart.

This release is unsigned. Native Windows installation and an actual upgrade cycle still need validation before broad distribution. The portable ZIP does not self-update.
