# Compact 2×3 listening widget

User request: a BusTAudioBooks phone widget occupying two columns and three rows. Existing session delegates implementation choices and signed APK delivery.

Use the existing provider so current widget instances survive an app upgrade. Change the default and preview to a vertical compact layout: flexible cover, two-line title, chapter, current-part progress/time, and playback controls. Keep the existing wide layout at 250dp and above. Android 12+ receives responsive RemoteViews so each widget/orientation selects its layout independently; older launchers select per-instance width and rerender on resize. Legacy minimum dimensions are 110×180dp; actual grid geometry is launcher-dependent. No playback, sync or account changes.

Alternatives considered: compressing the existing horizontal layout would squeeze the controls; a second provider would duplicate the widget picker and snapshot handling. A responsive existing provider keeps both shapes available.

Delivery: app/runtime 3.3.1, Android versionCode 7. Requires a signed APK; cannot be delivered by an Expo JS update. Install over existing app, then add or resize the home-screen widget to 2×3. New default dimensions do not forcibly resize an already placed widget.

Verification plan: native Kotlin API compile, existing native/Jest tests, typecheck/lint, Expo prebuild/resource generation, independent review, cloud release unit tests and APK assembly, then verify package/version/signing certificate and packaged compact layout/provider dimensions. Device/launcher interaction testing remains unavailable in this environment.

Local verification: 354 Jest tests / 49 suites and 14 native JUnit tests passed; TypeScript passed; lint has zero errors and the same four existing React hook warnings. Native files compile against real Android15/Media3 APIs with -Werror. Expo prebuild succeeds. Independent review identified global height and legacy orientation regressions; fixed by retaining 148dp minimum resize height (180dp initial height) and separate landscape/portrait RemoteViews on older Android. Compact artwork gives space to text/controls when resized shorter. Responsive layout entries use the same minimum height so width selects the wide variant. Seek labels shrink to fit at narrow widths.
