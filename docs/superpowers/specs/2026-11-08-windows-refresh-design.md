# Windows refresh and updates

User wants a more professional Windows application, styling closer to the phone, and automatic updates. Existing session delegates implementation order and routine choices to us; proceed without another design-approval round.

Keep Electron and private account sync. Match phone dark palette (#15101c background, #221a2e cards, #3a3147 borders, #ece8f1 text), violet default and blue/teal/orange/pink selectable accents saved per Windows installation. Add clear sidebar navigation, a continue-listening feature, balanced library cards and typography, consistent settings sections, and legible long chapter titles in the player. Preserve existing recovery flows, privacy boundaries and audio controls. Avoid new artwork dependencies.

Use electron-builder NSIS installer and electron-updater with the public AFK-Goblin/BusTAudioBooks-App GitHub Releases feed. Installer is a one-time replacement for old portable 1.0.0; preserve the existing package name/productName and resulting Electron userData directory and credentials. Standard background checks/downloads, progress, manual check, retry, and explicit Restart to update. Never restart automatically during playback; checkpoint before install and block if unsaved recoveries remain. Only installed Windows packages enable automatic updates; development/portable display a truthful unsupported state. Do not expose URLs/commands from renderer to updater. Library credentials never go to the update provider.

Approaches considered: portable self-replacement requires custom Windows process/filesystem handling and greater risk; a manual download notification does not fulfill requested automatic updating; standard installed NSIS updates are the implementation choice. GitHub workflow produces installer, blockmap and latest.yml as draft release, with clean package tests. Release publication depends on available repository access; do not claim live updates if artifacts are not published. Current unsigned distribution remains unsigned, documented. Deliver version 1.1.0 with downloadable installer if cross-build permits, retain portable fallback. Verify updater state and restart guard with Node tests, renderer with Chromium including existing real audio/race tests, inspect screenshots at desktop/minimum widths, build and inspect packaged contents. Native Windows installation/update still requires Windows validation; a Linux build cannot prove it.
